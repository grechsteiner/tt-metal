Which memory configs can the residual add use?

Every combination of input A, input B and output memory config was run on the Blackhole simulator with a 12 × 10 core grid and compared element by element with torch.add. The model runs this add DRAM interleaved today. Pick configs below to see what works with them, and why the rest fail.
