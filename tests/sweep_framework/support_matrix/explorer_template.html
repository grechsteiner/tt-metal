What the results say

    L1 per core for each config

    The bar on each row adds up these figures for the tensors that live in L1. They all start on the same first cores, so the sum is what those cores must hold. Each core has 1427 KB of L1. Row-major can also need temporary tile copies that the estimate leaves out.

    Source: tests/ttnn/nightly/unit_tests/operations/test_op_support_matrix.py, run on ttsim (Blackhole) with slow dispatch and a 12 × 10 compute grid.
